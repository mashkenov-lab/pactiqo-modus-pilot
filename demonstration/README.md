# Интерактивный тур MODUS

Публичный тур: https://pactiqo.com/modus/tour/. Откройте `index.html` локально в современном браузере; относительные пути к `tour.css`, `tour.js` и `assets/` нужно сохранить. Для самого тура не нужны сервер, ключи или внешние API.

Тур ведёт по двум учебным сценариям: заявка на оборудование и изменение спецификации. Изображения интерфейса и PDF получены из изолированного прогона работающего MODUS. Навигационные действия тура не изменяют рабочую платформу. Мессенджер и заранее заданные ответы помощника явно обозначены как имитация; внешние сообщения не отправляются.

Исходные файлы и все материалы скопированы по SHA-256 из принятого манифеста демонстрации. QA-снимки, ZIP, видео и зависимости в эту папку не включены. Локальная проверка автора тура и независимая проверка подтверждают оба сценария, страницы PDF, возврат/принятие и отсутствие горизонтального переполнения на 1440 и 390 px. Узкий viewport не считается проверкой физического телефона.

Работающий серверный учебный кабинет находится отдельно: https://pactiqo.com/modus/app/. Различие между кабинетом, туром и видео описано в [docs/WEB.md](../docs/WEB.md).
