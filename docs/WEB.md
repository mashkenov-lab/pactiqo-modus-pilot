## Варианты запуска

| Вариант | Запуск и зависимости | Хранение и помощник |
|---|---|---|
| Локальный автономный исходный пакет | Node.js 24; из корня `npm start`, без npm-зависимостей | Собственная учебная папка, случайные локальные пароли; внешний ИИ отключён |
| Облачная учебная поставка | `cd cloud`, `npm ci`, `npm test`; размещение по `cloud/README.md` | Приватный Blob, отдельный AES-GCM ключ, проверка ETag; помощник по детерминированным правилам |
| Полный Windows-комплект | Отдельный поставляемый установщик и настройка компонентов | Локальная платформа, отдельные Adapter/Codex/каналы; не входит двоичными файлами в этот репозиторий |

Для веб-поставки нужны защищённые серверные переменные Blob и отдельный ключ данных, описанные в `cloud/README.md`. Их значения не публикуются. Не требуется переносить личный профиль или рабочую базу владельца.

## Границы

Облачный кабинет — общий публичный учебный стенд. Посетитель может выбрать учебную роль; это не изолированная организация с конфиденциальными данными. Используются только синтетические ситуации и материалы. Исходные 20 случаев сохраняются; дополнительные явно учебные карточки могут появляться при показе и проверке.

Облачный помощник не является генеративной моделью и не обучает её. Он сохраняет исходный текст, предлагает категорию по правилам, уточняет подразделение и оставляет регистрацию человеку. Реальные WhatsApp, Telegram, почта, Bitrix, Adapter и фоновые локальные исполнители отключены. Внутреннее уведомление не считается доставкой в мессенджер. Самостоятельный таймер напоминаний не запущен.

Узкий браузерный viewport не является проверкой физического телефона. Корпоративные аккаунты, SSO, полноценная промышленная нагрузка, эксплуатационная приёмка и физические устройства остаются отдельными этапами.

`cloud/RELEASE_REPORT.md` сохранён без изменения как первичный отчёт о самостоятельной веб-поставке на момент его составления. Его раздел о будущем подключении основного домена описывает промежуточное состояние. Актуальный результат конечной публикации фиксируется в начале этого документа; поручений проверяющему на подключение нашего домена нет.
