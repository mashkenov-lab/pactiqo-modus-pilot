# Тестовые данные

Источник 20 записей: учебный набор конкурса, ссылка и SHA-256 исходного документа сохранены в `source/fixtures/modus-dataset.json`. Основные описания A-001…A-020 не заменены реальными письмами или данными владельца.

При первом `npm start` вызывается `seedDataset()`, затем `populateDiscussionDemo()`. Создаются 20 обращений, по 6 реплик и 3 материала на каждое: исходный PNG, PDF первой редакции и PDF исправленной редакции. Всего 120 реплик, 20 PNG и 40 PDF. Каждое обсуждение показывает замечание, исправление, отдельное согласование файла и следующий шаг.

`source/fixtures/discussion-scenarios.json` содержит тексты учебного обсуждения. `source/fixtures/discussion-materials/manifest.json` содержит хеши материалов. `selfcheck` скачивает через защищённый HTTP все 60 файлов и сверяет хеши. Повторный обычный запуск не наполняет базу заново и сохраняет изменения пользователя.

Учебные роли: `employee` / `employee2` — два автора; `owner` / `owner2` — два ответственных; `manager` — руководитель; `admin` — администратор. Их имена, компания, даты и история являются демонстрационными. Пароли генерируются случайно в собственной учебной базе; общих заранее опубликованных паролей нет.

Из наполнения не следует доставка уведомления в Telegram/WhatsApp. Локальная регистрация события, HTTP-ответ, провайдерный статус «sent», доставка и прочтение — разные факты. В этом пакете внешние отправки при наполнении отсутствуют.

Для нового запуска используйте новый пустой каталог, например `npm start -- --data ./demo-data/second-run --port 4391`. Существующая база без маркера конкурсного запуска не принимается. Не подставляйте `data-r5` основной установки или профили пользователя.
