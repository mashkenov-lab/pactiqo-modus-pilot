## Публикация на основном домене

Основной агент добавляет только:

```json
{"source":"/modus/app/:path*","destination":"https://pactiqo-modus-pilot.vercel.app/modus/app/:path*"}
```

И отдельный маршрут `/modus/app` на upstream `/modus/app/`. Глобальный `/api` основного сайта не перехватывать. Настройку DNS не требуется менять. Фактический вход, Cookie/Origin, файлы и PDF через конечный `https://pactiqo.com/modus/app/` должен проверить основной агент после включения proxy. На момент этого отчёта эта внешняя часть не заявляется проверенной данным исполнителем.

## Существенные границы

- Общий синтетический стенд, шесть открытых учебных ролей; пароль на странице. Не корпоративная закрытая среда и не изоляция каждого посетителя.
- Входящий помощник по простым правилам, без генеративной модели. Совет ИИ в обсуждении явно недоступен. Ни Codex inference, ни локальный Adapter в облако не перенесены.
- Внешняя почта/WhatsApp/Telegram/Bitrix и фоновые локальные исполнители отключены; корпоративные интеграции отдельно. Приёмка веб-ядра не является приёмкой доставки сообщения в мессенджер.
- Уведомления при изменении статуса внутри платформы работают; самостоятельный фоновый таймер эскалаций/напоминаний не запущен.
- 20 исходных кейсов сохранены. В живых тестах добавлены две явно учебные карточки, поэтому сейчас всего 22; MT-0022 принят автором после полного browser flow, MT-0021 остаётся незакрытым тестовым созданием с первого прогона.
- Для нагрузки сверх пилота нужны транзакционная база, отдельное хранилище вложений, управляемая идентификация, резервирование и эксплуатационная приёмка.

Основные инструкции, ограничения и схема хранения находятся в `README.md`. `source-file-manifest.json` содержит хеш каждого файла исходного пакета. Секреты, `.env*`, `.vercel`, node_modules, приватные сессии и локальные диагностические конфигурации не включены в этот манифест и должны быть исключены из публичного репозитория.
