# PACTIQO MODUS — от сообщения сотрудника до принятого результата

Конкурсный пакет для трека ГК «Модус Трейд», 13 ноября 2026 года. Рабочий MVP с локальным и облачным учебным запуском на основе **R6 4.0.0 b8**, исходный commit `ab11ca7046d6117c5754e3588afb0c747bf9d351`.

## Показ через браузер

Опубликованные адреса; конечный домен проверен 13.11.2026:

- [Обзор MODUS](https://pactiqo.com/modus/)
- [Рабочий учебный кабинет](https://pactiqo.com/modus/app/)
- [Интерактивный тур](https://pactiqo.com/modus/tour/)
- [Видео — 3:48,74, Full HD, русские субтитры](https://pactiqo.com/modus/modus-pilot.mp4)

Кабинет — общий стенд на синтетических данных с открытыми учебными ролями. Помощник в облачной версии работает по простым правилам и обозначен как **не генеративный ИИ**. Внешние мессенджеры отключены. Исходники веб-версии, её запуск и ограничения — в [cloud/README.md](cloud/README.md), различия вариантов и актуальный статус публикации — в [docs/WEB.md](docs/WEB.md).

Сотрудник рассказывает о проблеме обычным языком. Система помогает уточнить ситуацию, подготовить обращение, назначить ответственного и сохранить обсуждение. Исполнитель показывает результат, автор принимает его или возвращает на доработку. Ценность — сохранить обращение и довести его до понятного результата без пересылки контекста между отделами.

В этом репозитории есть сервер, интерфейс, бизнес-правила, тесты и 20 учебных примеров ТЗ. Локально работают регистрация, роли, маршрутизация, сроки, обсуждение, файлы, решения, история и аналитика. Облачный ИИ и реальные мессенджеры требуют отдельных подключений и в стандартном конкурсном запуске отключены. Их наличие в архитектуре не означает подтверждённую промышленную эксплуатацию.

## Быстрый запуск

Нужен **Node.js 24.x** с npm, современный браузер и свободный локальный порт 4389. Node, Adapter, Codex, личные профили и базы в пакет не входят. Устанавливать npm-зависимости для локального MVP не требуется.

```console
node --version
npm run verify:source
npm run selfcheck
npm test
npm start
```

Откройте **http://127.0.0.1:4389/**. При первом запуске программа создаст папку `demo-data` и файл `demo-data/ACCESS.txt` со случайными локальными паролями. Выберите «Администратор» и используйте пароль для `admin` из этого файла. Пароли не выводятся в журнал запуска и не входят в Git.

Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd` или прямые команды `node scripts/selfcheck.cjs`, `node scripts/test-core.cjs`, `node scripts/start-demo.cjs`. Если порт занят:

```console
npm start -- --port 4391
```

Остановка — `Ctrl+C`. Повторный запуск сохраняет ваши учебные изменения. Для нового чистого показа укажите новую папку: `npm start -- --data ./demo-data/new-demo --port 4391`. Не указывайте папку реальной установки: запуск принимает только пустой каталог или собственную ранее созданную учебную базу.

## Что показать за несколько минут

1. Под `admin` открыть список обращений: 20 случаев A-001…A-020 и назначенные ответственные.
2. Открыть MT-0001 → «Общее обсуждение». Просмотреть исходное изображение, PDF версии 1, замечание автора, PDF версии 2 и согласование. Перелистнуть обе страницы PDF. Согласование файла не закрывает дело.
3. Под `employee` создать учебное обращение. Под `owner` начать работу, запросить уточнение и предъявить результат. Под `employee` ответить, вернуть на доработку и затем принять исправленный результат.
4. Под `manager` проверить историю, фильтры и аналитику. Под `employee2` убедиться, что чужое обращение и его файлы недоступны.

Подробный [сценарий показа](docs/DEMO_RUNBOOK.md), [тестовые данные](docs/TEST_DATA.md), [матрица требований и проверок](docs/REQUIREMENTS.md), [архитектура и интеграции](docs/ARCHITECTURE.md), [ограничения](docs/LIMITATIONS.md), [план пилота](docs/PILOT_PLAN.md).

## Границы проверки

`selfcheck` создаёт временную базу, загружает все 20 обсуждений и 60 файлов через HTTP, сверяет SHA-256, проверяет права, путь до приёмки с возвратом и сохранение после перезапуска. `npm test` запускает переносимую группу тестов ядра; браузерные, Windows-установочные и реальные провайдерные проверки — отдельные группы. Число проверок и фактический результат записаны в [протоколе](evidence/VALIDATION.md).

Ранее проверенный полный Windows-комплект и установленная платформа — отдельный результат. Этот лёгкий пакет не содержит установщик или двоичные файлы его компонентов. Публичный HTTPS учебной веб-версии проверен отдельно. Реальный личный WhatsApp → бот после остановки теста, перенос медиа через мессенджеры, физический телефон, MAX, корпоративные аккаунты и Bitrix не объявляются принятыми.

## Состав и происхождение

- `source/` — неизменённое содержимое проверяемого source-архива b8: 182 файла исходников/материалов и 2 служебных файла архива; дополнительно 6 неизменённых статических `public/` файлов того же commit для полноты legacy-тестов. Всего около 9,30 МБ без сжатия.
- `scripts/` — отдельный учебный запуск, самопроверка, запуск переносимых тестов и проверка хешей.
- `cloud/` — отдельная облегчённая веб-поставка: 134 файла принятого манифеста и 2 документа происхождения; серверный wrapper, интерфейс и интеграционные тесты, без `.env`, `.vercel` и npm-зависимостей.
- `demonstration/` — исходники интерактивного тура и учебные материалы; действия тура отделены от серверной платформы.
- `presentation/` — текст выступления, SRT/WebVTT, ссылка и хеш принятого видео; тяжёлый MP4 в Git не включён.
- `docs/` — продукт, архитектура, демонстрация, данные, ограничения и пилот.
- `evidence/` — хеши и результаты, не содержащие рабочую базу или личные входы.

Хеши файлов `source/` приведены в [source-provenance.json](evidence/source-provenance.json) и [дополнении](evidence/supplemental-source-provenance.json). Исходники не заменяются позднейшими демонстрационными страницами. Протокол относится к локальному MVP; веб-тур и видеопоказ, если добавлены, обозначаются отдельно.

В Git сохранена **отфильтрованная настоящая история разработки**: 52 коммита, затрагивающие разрешённые исходные пути, из 66 коммитов исходного локального репозитория. Авторы, даты, сообщения и содержимое сохранены. Пути перенесены под `source/`, поэтому SHA коммитов изменились; [карта происхождения](evidence/history-provenance.json) связывает исходные и экспортированные SHA. Исключённые коммиты касались журналов/операционных материалов вне разрешённого состава. Учебный запуск и конкурсные документы добавлены отдельным настоящим коммитом в дату подготовки пакета.

Репозиторий предназначен для конкурсного рассмотрения. Публичная лицензия на исходники этим пакетом не предоставляется; сторонние компоненты сохраняют свои лицензии, включая PDF.js в `source/r4-public/pdfjs/LICENSE`.
