# PACTIQO MODUS R6 — локальная установка

Установщик Windows: `PACTIQO-MODUS-Suite-r6-4.0.0-bN-Setup.exe`. Установка в отдельную папку, без копирования личных входов Codex и профиля Adapter. Подписей и внешней приёмки этот документ не подтверждает. Вход пользователя и подключение каналов настраиваются отдельно. При недоступном Adapter локальный интерфейс должен оставаться доступен; сведения о связи проверяйте в приложении.

Для автоматизированной установки в пустую отдельную папку:

```powershell
& '<путь к Setup.exe>' --silent --root 'D:\MODUS-TEST' --port 4839 --empty
```

Для обновления используйте ту же папку. Дождитесь завершения задач и отправок; остановка может быть отклонена, пока они выполняются. Запуск и остановка из установленной версии:

```powershell
& 'D:\MODUS-TEST\versions\<версия>\runtime\node.exe' 'D:\MODUS-TEST\versions\<версия>\suite-control.cjs' start 'D:\MODUS-TEST'
& 'D:\MODUS-TEST\versions\<версия>\runtime\node.exe' 'D:\MODUS-TEST\versions\<версия>\suite-control.cjs' stop 'D:\MODUS-TEST'
```

После остановки создание локальной резервной копии:

```powershell
& 'D:\MODUS-TEST\versions\<версия>\runtime\node.exe' 'D:\MODUS-TEST\versions\<версия>\suite-backup.cjs' backup 'D:\MODUS-TEST'
```

Копия платформы создаётся в `data\backups` и включает учётные записи, карточки, вложения и реестры операций. Она может содержать конфиденциальные данные: храните её в защищённой папке. Часть привязок и входов зависит от Windows и не переносится автоматически на другой компьютер. Личный профиль Adapter в копию платформы не входит. Для проверки восстановления используйте только отдельный пустой каталог:

```powershell
& 'D:\MODUS-TEST\versions\<версия>\runtime\node.exe' 'D:\MODUS-TEST\versions\<версия>\suite-backup.cjs' restore '<абсолютный путь к папке копии>' 'D:\MODUS-RESTORE-CHECK'
```

Проверяются пути, размер и SHA-256 каждого файла; существующие данные не перезаписываются. Не подменяйте этой проверкой восстановление работающей системы. Флажок автозапуска отражает собственный ярлык выбранной папки установки; обновление сохраняет настройку, если её явно не изменяли. Отдельно включить или выключить автозапуск можно без переустановки через `Setup.exe --autostart enable --root <папка>` или `Setup.exe --autostart disable --root <папка>`. Команда работает только с ярлыком этого комплекта в Startup текущего пользователя; чужой ярлык с таким же именем не перезаписывается и не удаляется. Тихая установка без `--autostart` сохраняет настройку. Отправка со статусом «неизвестно» требует проверки квитанции, а не повторной отправки.

Если обновление прервано до завершения первого запуска, обычный запуск останавливается сообщением о восстановлении. После остановки комплектa запустите установленный скрипт **новой версии**, которая выполняла обновление:

```powershell
& 'D:\MODUS-TEST\versions\<новая версия>\runtime\node.exe' 'D:\MODUS-TEST\versions\<новая версия>\install-suite.cjs' recover 'D:\MODUS-TEST'
```

Восстановление проверяет резервную копию, сохраняет изменённую папку платформы отдельно и возвращает прежнюю версию. При повторном запуске после сбоя продолжает по журналу; путь сохранённой изменённой папки возвращается в результате команды. Перед ручными действиями с ней сохраните обе копии.

Чтобы импортировать уже открытое письмо Gmail, администратор в «Компания → Каналы и почта» выбирает подключение и указывает точные тему и email отправителя. Кнопка предпросмотра показывает метаданные открытого письма без чтения тела; она не доказывает совпадение с ранее выбранной строкой входящих. После проверки ID, отправителя, темы и аккаунта отдельно подтвердите чтение, затем отдельно подтвердите импорт снимка. Если письмо или аккаунт изменились, повторите предпросмотр. Вложения не импортируются.
